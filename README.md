## Featured project: ULTRON / AI Agent Farm

ULTRON is a Windows-based multi-agent automation project I built and operate locally. The private source repository contains the full runtime and internal automation code; this public portfolio contains a sanitized case study and selected public-facing assets.

Key capabilities developed in the project include:

- local LLM inference with Ollama
- Python automation and REST APIs
- JSON / SQLite state
- durable jobs and schedules
- human approval boundaries
- current-link verification for application workflows
- Stripe payment observation
- Twilio notification workflows
- Wix publishing integrations
- QA and regression tests
- hidden background recovery processes
- Git/GitHub-based source control

The project intentionally keeps states such as draft, submitted, paid, payout, and bank arrival separate rather than inferring success.
